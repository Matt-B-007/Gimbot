# Getting help with Gimbot

Gimbot is an unofficial hobby project, not an OBSBOT product. OBSBOT's own
support can't help with it, and Gimbot can't help with problems in the
camera's firmware.

- **Something doesn't work:** use **Help (?) › Report a problem** in the app,
  or run `gimbot --report` in a terminal, then open an issue with the bug
  report form and attach the saved file.
- **Gimbot won't start:** run `gimbot --self-test` in a terminal and include
  what it prints.
- **An update went wrong:** **Settings › App › Go back**, or
  `gimbot --rollback`, reinstalls the version you had before.
- **Questions and ideas:** open an issue and say it's a question.

The README's [Problems?](README.md#problems) section covers the common ones
(camera not found, preview busy in another app, the SDK).

Replies come when the maintainer has time; there's no guaranteed response
time.
